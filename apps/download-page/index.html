Install

Install WisePath in three steps

WisePath is installed directly from an APK file instead of the Play Store, so Android will ask you to allow the install once.

  1. Download the APK

    On your Android phone, tap Download for Android. The file is about 100 MB, so Wi-Fi is a good idea.

  2. Open the file and allow the install

    Open the downloaded file from your notifications or the Files app. If Android blocks it, tap Settings, turn on Allow from this source, then go back.

  3. Install and sign in

    Tap Install, open WisePath, and create your student account to start your assessment.

If Google Play Protect shows a warning, that's because the app isn't from the Play Store. Tap More details, then Install anyway.
